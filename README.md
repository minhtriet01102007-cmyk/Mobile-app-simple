# Tasky - Mobile App đơn giản bằng HTML

Đây là một mobile web app quản lý công việc đơn giản.

## Công nghệ
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Chức năng
- Thêm công việc
- Đánh dấu hoàn thành
- Xóa công việc
- Xóa toàn bộ công việc đã hoàn thành
- Hiển thị % tiến độ
- Dark mode
- Lưu dữ liệu trên trình duyệt

## Cách chạy

Cách đơn giản nhất:

1. Mở thư mục dự án bằng VS Code.
2. Mở `index.html`.
3. Dùng extension **Live Server** trong VS Code.
4. Chọn **Open with Live Server**.

Hoặc chỉ cần mở trực tiếp `index.html` bằng Chrome.
